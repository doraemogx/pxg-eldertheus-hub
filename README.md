# PXG Hub — Eldertheus Edition

Guia independente de Pokémon PXG com foco no personagem Eldertheus, nível 598, clã Raibolt.

A aplicação é estática; abra `index.html` no navegador.

## Publicação no GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main / (root).

## Observações
As chances de captura calculadas são cenários hipotéticos e não probabilidades oficiais publicadas pelo PXG.

Projeto de fãs, sem associação à PokeXGames, Nintendo ou The Pokémon Company.
